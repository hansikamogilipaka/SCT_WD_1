# 🌐 SkillCraft Technology - Interactive Navigation Website

This project is a modern and responsive website featuring an interactive navigation menu with dynamic effects. The navigation bar remains fixed and visible across all sections, enhancing user experience and accessibility.

## ✨ Features

- 📌 Fixed Navigation Bar (visible on all sections)
- 🎨 Color change effect on scroll
- 🖱️ Hover animations on menu items
- 🚀 Smooth landing animation on page load
- 🖼️ Web development themed images and layout
- 📱 Responsive and clean UI design
- 💻 Beginner-friendly and professional structure

## 📚 About the Project

This website is designed based on **SkillCraft Technology** theme and focuses on **Web Development** instead of AI. It highlights the importance of building responsive, modern, and user-friendly websites using core web technologies.

## 🛠️ Technologies Used

- HTML5  
- CSS3  
- JavaScript
